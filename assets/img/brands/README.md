# Logotipos de las marcas de descuentos

Van sobre las tarjetas **azul oscuro**, así que se necesitan en **blanco o de un
solo color claro**, fondo transparente. SVG preferido (si no, PNG a 2x).

Guardar con estos nombres exactos:

| Archivo | Marca |
|---|---|
| `holafly.svg`      | Holafly |
| `getyourguide.svg` | GetYourGuide |
| `insta360.svg`     | Insta360 |
| `discovercars.svg` | DiscoverCars |

Se colocan dentro de `.deal__brand` en `index.html` y `servicios.html`
(mismo bloque en los dos). Altura de referencia: ~24 px.
